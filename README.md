System till fiktiv brädspelförening. Medlem, spel och bokninghanterare. Utvecklad med WPF och .NET.

För att köra programmet via terminalen:

git clone https://github.com/indium731/SpelCenter.git
cd SpelCenter
dotnet run

Via Visual Studio:
Clona repon
Dubbelclicka .sln filen för att öppna med Visual Studio
F5 för att bygga och köra programmet

Via .zip fil
Ladda ner zip fil
Extrahera fil.
Navigera till den skapade mappen via terminalen
kör "dotnet run"

Andra metoder kan ej garanteras att vara fungerande.
